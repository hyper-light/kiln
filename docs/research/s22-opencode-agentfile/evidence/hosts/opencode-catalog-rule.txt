How kiln derives opencode 2.2.7's reachable provider hosts (docs/research/s18-host-in-vm/evidence/part4/scripts/oc_hosts.py):
every API of a chat, decision or image model in opencode's catalog whose @opencode/ai package the build ships
(provider.ts's builtins), at an https base_url with a fixed public name, leaving out the packages that build their
own URL from an account, region or resource (models-dev.ts's BUILDS_OWN_URL). Of those, Cloudflare's two build it at
a fixed host with the account in the path (gateway.ai.cloudflare.com, api.cloudflare.com), so those hosts are named
from their own modules (hosts.tsv); Azure's, Bedrock's and Vertex AI's hosts follow the person's resource or region
and stay out (ROOT's call of 2026-11-13). The catalog is opencode's default
source (models-dev.ts's defaultSource and catalogPath), as fetched 2026-11-13: sha256 in hosts.tsv. Numbered
excerpts of opencode at tag v2.2.7, fetched 2026-11-13 with curl -L, each with the whole file's SHA-256.
