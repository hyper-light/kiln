# Amp

Amp is a coding agent and development environment built for the frontier.

This is an index of Amp's product pages and documentation for agents and other
programmatic readers. Each documentation link serves the raw Markdown rendition of a page.
The human-readable HTML version of a page is at https://ampcode.com/docs with the
`/markdown` path segment removed (for example https://ampcode.com/docs/prompting).

## Product

- [Pricing](https://ampcode.com/pricing): Tiers, included agent and orb usage, and answers to common billing questions. The tiers are also in Markdown at https://ampcode.com/docs/markdown/pricing.
- [What Are Orbs?](https://ampcode.com/what-are-orbs): Cloud sandboxes where each Amp thread gets its own machine with your repository.
- [Models](https://ampcode.com/models): Context windows, providers, and capabilities of the models Amp knows about.
- [Chronicle](https://ampcode.com/chronicle): Amp news, notes from the team, and podcast episodes.
