  4482	### Supplied agent and harness startup (D54, continued)
  4483	
  4484	A supplied directory or archive may hold its command in the root `agent.json` or
  4485	`harness.json`, with the user-approved fields `entrypoint` (a command string) and
  4486	`options` (an optional array of literal arguments). The same applies after a Git or
  4487	HTTP source is fetched. A nonempty entrypoint is split into quoted/escaped words, with
  4488	no implicit shell or variable, glob or command substitution; options follow as separate
  4489	arguments, including whitespace and empty strings exactly as given. An explicit `nohup`
  4490	is left as an ordinary program. No `ENTRYPOINT` or `CMD` scoping syntax is added to an
  4491	Agentfile, and startup does not install a program through `RUN` or `VOLUME`.
  4492	
  4493	`startup::config` normalizes the simple descriptor to the existing OSI config, using the
  4494	Agentfile's declared name; `shards build agent` and `shards build harness` use the
  4495	explicit `-t` repository's basename instead, never a filesystem name. With no explicit
  4496	name a simple descriptor is refused, while legacy OSI input keeps its own name. The
  4497	full OSI descriptor remains readable with its schema,
  4498	path and platform checks. `DomainConfig` is a graph operation over the unpacked source,
  4499	so native builds and the BuildKit frontend run the same regular-file check and parser
  4500	before copying `osi.json` beside the domain. Symlinks and non-regular descriptors are
  4501	refused. A missing descriptor retains passive layout compatibility. The existing domain
  4502	content checks still refuse escaping links, special files and set-ID bits.
  4503	
  4504	At runtime the domain's own root and `bin` precede the system directories on `PATH`,
  4505	which is inherited by children too. This makes a supplied bare `codex` or `claude` work,
  4506	and makes `nohup codex ...` find the same artifact's executable. This changes neither
  4507	its cgroup nor its filesystem, process or network grants. Output routing is a separate
  4508	contract; this startup decision makes no output grants.
